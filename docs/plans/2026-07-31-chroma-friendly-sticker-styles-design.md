# 去背友善貼圖風格擴充設計

## 目標

在既有 AI 貼圖工作室保留五種視覺風格，新增四種適合純色背景去除的風格，讓使用者有更多選擇，同時避免柔邊、光暈、陰影與半透明材質降低最終動態貼圖品質。

完成後共有九種風格：

- 忠於參考圖（`reference`）
- Q 版插畫（`chibi`）
- 賽璐璐（`cel`）
- 黏土（`clay`）
- 手繪（`sketch`）
- 扁平向量（`flat-vector`）
- 粗線條卡通（`bold-cartoon`）
- 復古漫畫（`retro-comic`）
- 像素藝術（`pixel-art`）

## 使用者介面

風格選擇維持直接按鈕，不增加下拉選單或分類層級。九個選項以響應式 3×3 網格呈現；窄螢幕仍可縮成兩欄，確保文字可讀與觸控範圍充足。

新增中英文名稱，並保留原本五種風格的顯示名稱與預設值。使用者切換風格後，其餘角色設定、系列資料與已規劃貼圖詞不受影響。

## 生成提示詞

四種新增風格各自使用明確且互不重疊的提示詞：

- 扁平向量：封閉輪廓、實心純色色塊、無漸層、無紋理、無半透明。
- 粗線條卡通：粗且一致的深色外框、簡化造型、實心填色、無筆刷毛邊。
- 復古漫畫：清楚墨線、有限色盤；網點只允許出現在角色內部，不得碰觸外輪廓；禁止紙張背景紋理。
- 像素藝術：硬邊方形像素群、有限色盤、無反鋸齒、無模糊、無漸層與光暈。

所有風格仍共用既有的純色背景規則，包括背景顏色一致、前景不得使用近似色、禁止場景／投影／光暈，以及保持封閉銳利邊緣。新增提示詞只強化風格特有風險，不重複取代共用規則。

## 資料與相容性

擴充 `SpriteSheetStyle` 型別、UI 選項與草稿解析白名單。既有草稿使用的五種值保持不變，因此不需資料遷移；新風格草稿可以正常儲存、恢復與從作品集重新開啟。

若草稿包含未知風格，沿用目前拒絕無效資料的行為，不進行猜測式轉換。

## 驗證

- 單元測試確認四種新增風格都有對應提示詞。
- 測試提示詞包含各風格必要的去背限制。
- 草稿持久化測試涵蓋新增風格並維持舊草稿相容性。
- UI 原始碼測試確認九個選項與響應式網格存在。
- 執行 TypeScript、i18n、完整測試與 production build。
